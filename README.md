# Random Color Generator

This is a small web project I built using HTML, CSS and JavaScript. It generates random RGB colors whenever the Generate Color button is clicked and displays the selected color on the webpage.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Generates random RGB colors.
- Changes the background color dynamically.
- Displays the generated color on the webpage.
- Uses a button click to generate new colors.

## How It Works

1. Open the webpage in your browser.
2. Click the Generate Color button.
3. A random RGB color is generated.
4. The generated color is applied to the color display area.
5. Click again to generate another color.
